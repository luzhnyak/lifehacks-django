# Зображення дописів

В адмінці відкрийте або створіть Post. У блоці «Зображення допису»
завантажте файли, додаючи рядки кнопкою додавання зображення.
Позначте «Головне» біля потрібного файлу та збережіть допис.
Нові зображення й вибір головного можна зберегти одночасно.

Позначка «Головне» перемикається між зображеннями. Якщо зняти її
або видалити головне зображення, допис залишиться без головного Image.
На сайті вибране зображення використовується як раніше — у картках,
на сторінці допису та в метаданих для поширення.

Міграція `0007_postimage` додає наявні Image до галерей відповідних
дописів без копіювання або перейменування файлів. Перед запуском
оновленої адмінки виконайте `python manage.py migrate`.
